# 🎨 Image Studio

🇬🇧 [English version](README.md)

Расширение SillyTavern для генерации изображений **по запросу, из собственной панели**. В чат ничего не отправляется. Оно использует подключения, которые вы уже настроили в **sillyimages** или **SLAY Images**, либо работает со своим собственным подключением.

Работает на компьютере и телефоне (на телефоне — нижняя шторка, на компьютере — перемещаемое окно).

## Возможности

- **Отдельно генератор, подключение и модель.** В чате можно оставить NovelAI, а в Студии использовать Nano Banana.
- **Промпт с заменяемыми `{тегами}`.** Пишете `1girl, {style}, {quality}` и меняете каждую часть в отдельном поле.
- **Референсы персонажей (до 4).** Дайте им имена и пишите `personA kissing personB`.
- **Картинка, текст или оба сразу для каждого референса.** У каждого персонажа свой текстовый и негативный промпт.
- **Референс-картинки с назначением.** Берите позу, стиль рисунка, композицию, одежду, фон или картинку целиком, чтобы воссоздать её с вашими персонажами. Каждую связывайте с промптом через `{тег}`.
- **Библиотека референсов.** Сохранённые персонажи и референс-картинки для любых генераций.
- **Интерфейс на английском и русском** (Авто, English или Русский).
- **Библиотека изображений.** Сохраняйте результат вместе с промптом, переменными, моделью и референсами, которые его создали.
- **Кнопка стиля SLAY**, открывающая галерею стилей самого SLAY Images.
- **Перемещаемая плавающая кнопка, ползунок прозрачности, сворачиваемая панель.**

## Установка

Устанавливается из самого SillyTavern, копировать файлы вручную не нужно:

1. В SillyTavern откройте панель **Расширения** (значок пазла).
2. Нажмите **Установить расширение**.
3. Вставьте этот адрес и подтвердите:

   ```
   https://github.com/smolsn3k/st-img-studio
   ```

4. Выберите установку **для всех пользователей** или **только для вас**, затем перезагрузите страницу.

Открыть панель можно плавающей кнопкой 🎨, меню волшебной палочки (✨) → **Image Studio** или **Расширения → Image Studio → Открыть Image Studio**. Пункты в меню палочки и в расширениях появляются, как только SillyTavern построит эти меню, даже если на медленном телефоне это происходит позже.

**Обновление:** откройте **Расширения → Управление расширениями** и нажмите кнопку обновления рядом с Image Studio (или «обновить всё»), затем перезагрузите страницу.

## Три выбора на вкладке «Создание»

| Выбор | Что это |
| --- | --- |
| **Расширение-генератор** | `sillyimages`, `SLAY Images` или «Автономно» (собственное подключение Image Studio). |
| **Профиль подключения** | Сохранённое подключение в этом расширении: тип API, адрес и ключ. Для SLAY есть ещё «Текущие настройки SLAY». |
| **Модель** | Выбирается из списка, который принадлежит выбранному генератору (см. ниже), независимо от модели самого расширения. «Модель профиля» берёт модель из профиля. «Другая…» позволяет ввести id вручную. ↻ обновляет список. |

Модель не может сменить подключение. NovelAI напрямую и Gemini — это разные адреса с разными ключами, поэтому для сценария «NovelAI в чате, Nano Banana в Студии» нужен профиль, указывающий на подключение к Nano Banana (ключ Gemini, прокси или Naistera, который отдаёт обе модели). Выбор модели запоминается отдельно для каждого профиля.

### sillyimages

Профили берутся из профилей подключения sillyimages. Список моделей — это то, что возвращает собственный провайдер sillyimages для выбранного профиля (тот же список, что на его странице настроек), с его названиями, так что вы видите только модели sillyimages.

**Студия никогда не меняет sillyimages.** Для каждой генерации или запроса списка она работает с приватной копией настроек sillyimages (подключение выбранного профиля плюс ваша модель из Студии). Настоящие настройки sillyimages не изменяются, а если SillyTavern сохраняет настройки во время генерации, сохраняются исходные значения. Модель и подключение для чата остаются такими, как вы их задали. Единственное, чего стоит избегать: запускать картинку из чата через sillyimages в тот самый момент, когда Студия генерирует изображение, — sillyimages на короткое время прочитает копию Студии.

На вкладке «Настройки» есть **Импортировать стили расширения как варианты для {style}** — она копирует стили sillyimages в переменную `{style}`.

### SLAY Images

SLAY не предоставляет API другим расширениям, поэтому Image Studio сама формирует запросы по настройкам SLAY. Поддерживаются OpenAI-совместимые подключения, Gemini, Naistera и произвольный URL.

Список моделей для подключения SLAY строится так же, как у самого SLAY: из списка моделей подключения (для Naistera — фиксированный список SLAY). Image Studio никогда не записывает ничего в подключение или модель SLAY.

- **🎨 Выбрать стиль** открывает галерею стилей самого SLAY. Выбранный стиль добавляется в промпт блоком `[STYLE: …]` — в том же формате, что использует SLAY. Он виден и в предпросмотре итогового промпта. **✕** сбрасывает стиль.
- По умолчанию Студия хранит свой стиль и после выбора возвращает чатовый стиль SLAY. Отметьте **Общий стиль с чатом**, чтобы использовать текущий стиль SLAY.
- Если видите «Кнопка стиля SLAY не загружена», один раз откройте панель настроек SLAY Images и повторите.
- Naistera принимает референс-картинки только для моделей Grok и Nano Banana.

### Автономно

Настраивается на вкладке «Настройки».

- **Gemini / прокси Nano Banana:** адрес и API-ключ (собственный адрес Google или любой совместимый прокси). Соотношение сторон и размер для моделей Pro.
- **NovelAI:** используется ключ NovelAI, уже сохранённый в SillyTavern (Подключения API → NovelAI). Сэмплер, планировщик, шаги, guidance, размер, сид, decrisper и variety boost — на вкладке «Настройки».

## Промпты и переменные

Напишите любой `{name}` в основном или негативном промпте — переменная создастся автоматически.

- Введите значение или выберите сохранённый вариант из списка.
- **★** сохраняет текущее значение как **именованный вариант** (название + содержимое). Откройте **Изменить сохранённые варианты** под переменной, чтобы переименовать вариант, изменить содержимое, применить или удалить его. В списке показаны названия; выбор варианта подставляет его содержимое в промпт.
- **Переименование переменной:** нажмите на её имя (часть в `{ }`). Все `{old}` в промпте и негативном промпте переименуются тоже.
- 🗑 удаляет переменную.
- Переменные, не использованные в промпте, затемнены.
- `{{char}}` и `{{user}}` по-прежнему работают.
- **Итоговый промпт (предпросмотр)** показывает, что именно будет отправлено.

## Референсы персонажей

До **4 персонажей** на изображение. Добавляются на вкладке «Создание» кнопкой **＋ Добавить референс персонажа** — из библиотеки на вкладке «Референсы» или загрузкой новой картинки.

- **Дайте имя** каждому персонажу (например, `personA`) и пишите имена в промпте: `personA kissing personB`. Плашки под слотами вставляют имя в промпт. Если персонаж с картинкой не упомянут в промпте, вы получите предупреждение.
- **Отправлять как:**
  - **Картинка + текст:** отправляется картинка, и вписывается текстовый промпт.
  - **Только картинка:** отправляется только картинка.
  - **Только текст:** без картинки, используется только текст.
- **Текстовый промпт:** способ передачи зависит от модели, чтобы модель действительно его прочитала:
  - **Gemini, OpenAI-совместимые, Naistera, SLAY:** описание вписывается после имени (`personA (red hair, green eyes) kissing personB (blue hair)`) **и** перечисляется в блоке «Characters (draw each exactly as described)» в конце.
  - **NovelAI V4 / V4.5 через sillyimages:** используются настоящие промпты персонажей NovelAI. Промпт отправляется как `base | character 1 | character 2`, негатив каждого персонажа — в соответствующей позиции. Пишите основу как теги сцены (`2girls, kissing`), а текст персонажа — как теги (`girl, red hair, green eyes`).
  - **NovelAI через «Автономно»:** у собственной точки SillyTavern нет промптов персонажей, поэтому описания добавляются к промпту как теги.
- **Негативный промпт:** негатив каждого персонажа работает по тем же правилам (для NovelAI V4 — по позициям, в остальных случаях — объединяется с негативным промптом). Для персонажей «только картинка» не используется.
- **Картинка + текст:** если картинка и текст расходятся, обычно побеждает картинка. Используйте **Только текст**, когда внешность должен определять текст.
- **Посмотреть, что отправлено:** «Итоговый промпт (предпросмотр)» показывает это до генерации, а **Отправленный промпт** под каждым результатом — после.
- **Персонажей только с текстом** (без картинки) можно создать на вкладке «Референсы» кнопкой **＋ Новый персонаж только с текстом**.
- **Использовать как персонажа** на результате или картинке из библиотеки добавляет её как персонажа — чтобы сохранять облик персонажа.
- Флажок **Отправлять** отключает все референсы, не очищая слоты.

Примечания:
- **NovelAI** не принимает референс-картинки, но использует текстовую часть.
- Модели, принимающие меньше 4 референс-картинок, берут первые и сообщают об этом.
- Картинки уменьшаются до 1024 px и отправляются в PNG.

## Референс-картинки

До **3 референс-картинок** на изображение, задаются на вкладке «Создание» в разделе **Референс-картинки** (**＋ Добавить референс-картинку**, затем выберите сохранённую или загрузите новую). Сохранённые лежат на вкладке **Референсы** в разделе **Референсы**.

У каждой референс-картинки есть **назначение**, чтобы модель знала, что из неё взять, а что проигнорировать:

| Назначение | Что берётся |
| --- | --- |
| **Поза** | Поза тела, положение конечностей и ракурс камеры. Но не человек, одежда или фон. |
| **Стиль рисунка** | Стиль, цвета, освещение и манера отрисовки. Но не её объекты. |
| **Композиция** | Раскладка, кадрирование, ракурс и перспектива. |
| **Одежда** | Одежда и аксессуары. Но не человек и не поза. |
| **Фон** | Окружение. Но не люди. |
| **Картинка целиком (воссоздать)** | Всё: композиция, поза, стиль и настроение, но с **вашими персонажами** вместо её объектов. Для запроса «сделай картинку как эта, но с моим персонажем». |

**Связь с промптом через `{тег}`.** У каждой референс-картинки есть имя-тег (показывается как `{pose}`, `{artstyle}`, `{like}`…; его можно переименовать). Нажмите на её плашку над промптом или впишите тег вручную, например:

```
personA sitting at a cafe, in {pose}, drawn in {artstyle}
```

Image Studio превращает каждый тег в понятную инструкцию, указывающую на эту картинку («поза с референс-картинки “pose”»), и сообщает модели, какая картинка какая. Если тег не вписать, инструкция добавится в конец промпта сама, так что референс не будет проигнорирован. В тегах можно использовать любые буквы, в том числе русские.

- **Текст:** у каждого референса может быть ещё описание словами (`сидит по-турецки, смотрит через плечо`) и **негатив** (`скрещённые руки`). С тегом слова вписываются рядом с инструкцией.
- **Отправлять как:** **Картинка + текст**, **Только картинка** или **Только текст** — как у персонажей. Референсам только с текстом картинка не нужна (**＋ Новый референс только с текстом** на вкладке «Референсы»); тогда тег заменяется вашими словами.
- **Несколько сразу:** например, референс позы и референс стиля вместе, у каждого свой тег.
- **Лимиты картинок:** референс-картинки учитываются в лимите модели после ваших персонажей. Если лимит достигнут, лишняя картинка пропускается (вы увидите уведомление), а её текст всё равно используется.
- **NovelAI** не принимает референс-картинки, поэтому используется только текст (тег заменяется словами, а негатив объединяется с негативным промптом).
- **Использовать как референс-картинку** на результате или картинке из библиотеки превращает её в референс. **Использовать как персонажа** — в персонажа.
- Флажок **Отправлять** рядом с «Референс-картинки» отключает их все, не удаляя. Записи библиотеки запоминают свои референс-картинки, экспорт/импорт переносит их вместе с записями.
- Референсы поз из прошлых версий преобразуются автоматически (назначение: «Поза»).

## Язык

**Настройки → Язык:** **Авто** следует языку SillyTavern, либо выберите **English** / **Русский**. Меняется только интерфейс Image Studio и его сообщения. Ваши промпты, имена и сохранённые записи не переводятся, а текст, отправляемый моделям изображений, остаётся на английском.

## Библиотеки

Обе хранятся в **хранилище вашего браузера** (IndexedDB): они привязаны к устройству и браузеру и не синхронизируются.

- **Вкладка «Библиотека»:** сохранённые результаты с поиском. Нажмите на запись, чтобы открыть:
  - **Название**, **Промпт (с {тегами})** и **Негатив** редактируются. **Сохранить изменения** сохраняет правки.
  - **Использовать этот промпт** восстанавливает шаблон, негативный промпт, значения переменных, генератор, профиль, модель и референсы (уже существующие переменные сохраняют свои варианты).
  - **Во весь экран**, **Скачать**, **Использовать как персонажа**, **Использовать как референс-картинку**, **Экспорт** (только эта запись) и **Удалить**.
  - Необязательное **автосохранение** включается на вкладке «Настройки».
- **Экспорт / импорт:** кнопки вверху вкладки «Библиотека».
  - **Экспорт промптов** создаёт небольшой файл `.json` с промптами, переменными, моделями и данными персонажей — без картинок.
  - **Экспорт с картинками** включает и картинки (файл может получиться большим).
  - **Импорт из файла** добавляет записи из файла, созданного Image Studio. Уже имеющиеся записи пропускаются. Записи без картинки показываются с плашкой «T» и работают как обычные: откройте и нажмите **Использовать этот промпт**. Персонажи, использованные в импортируемых записях, тоже добавляются на вкладку «Референсы».
- **Вкладка «Референсы»:** сохранённые персонажи и референс-картинки (переключатель **Персонажи / Референсы**). У персонажей есть имя, текстовый промпт, негативный промпт и режим отправки; у референс-картинок ещё есть назначение и имя-тег.

## Интерфейс

- **Плавающая кнопка:** перетащите куда угодно, положение сохраняется. Нажмите, чтобы открыть.
- **Окно:** на компьютере его можно двигать за заголовок. На телефоне это нижняя шторка.
- **Во весь экран:** нажмите на результат (или кнопку **⛶ Во весь экран**), чтобы открыть его крупно. Нажмите на картинку — масштаб 100% с прокруткой, ещё раз — вписать. ✕ или нажатие вне картинки закрывает. ⬇ скачивает.
- **Ползунок ◐** (в заголовке): прозрачность панели, чтобы видеть чат за ней.
- **▾** сворачивает панель, **✕** закрывает.
- **Скрыть плавающую кнопку:** снимите флажок **Показывать плавающую кнопку 🎨** на вкладке «Настройки» или в блоке расширений. Открывайте из меню палочки или из блока расширений.
- **Сбросить положение кнопки и окна** — на вкладке «Настройки».

## Если что-то не работает

- **Не открывается (телефон или компьютер):** откройте **Расширения → Image Studio**. В заголовке указана установленная версия (так видно, что обновление применилось). **Открыть Image Studio** открывает всплывающее окно; при получении нажатия появляется короткое сообщение «открываю…», а строка статуса под кнопкой сообщает, получилось ли.
- **Image Studio — отдельное всплывающее окно.** Оно рисуется в «верхнем слое» браузера, поэтому появляется поверх меню и панелей SillyTavern, а не под ними; если поверх него появится что-то другое, оно поднимается обратно. Собственные уведомления SillyTavern не могут отображаться над ним, поэтому пока оно открыто, они показываются внутри окна.
- **Красная кнопка ⚠ (внизу слева):** появляется, если Image Studio не загрузилось или столкнулось с ошибкой, которую не может исправить. Нажмите на неё, чтобы увидеть причину, затем **Copy** и отправьте этот текст тому, кто поддерживает расширение. Тот же отчёт есть в **Настройки → Запустить самопроверку**.
- **Другие способы открыть:** плавающая кнопка 🎨, меню палочки (✨), команда `/imagestudio` или добавьте `?imagestudio` в конец адреса SillyTavern (например, `http://localhost:8000/?imagestudio`) — это ещё и вернёт скрытую плавающую кнопку.
- **Окно открывается, но его не видно:** Image Studio проверяет это сама и поднимает окно над тем, что его закрывает. Только если на вашем устройстве это невозможно, оно показывается внутри блока расширений, и строка статуса об этом сообщает. (Нужен браузер с Popover API: Chrome/Edge 114+, Safari 17+, Firefox 125+. В более старых используется обычное плавающее окно.)
- **Нет пункта в меню палочки или в расширениях:** они добавляются, когда SillyTavern построит эти меню, на телефоне это может занять несколько секунд. Плавающая кнопка работает всегда.
- **Красная строка «⚠ …» под вкладками** означает, что одна часть панели не загрузилась, остальное работает. Отправьте этот текст, когда будете сообщать о проблеме.
- **Расширение «(не найдено)»:** нажмите **Пересканировать расширения и профили** на вкладке «Настройки». Image Studio находит sillyimages и SLAY Images через список установленных расширений SillyTavern.
- **Ошибки NovelAI:** проверьте, что ключ NovelAI сохранён в «Подключения API».
- **«API key contains invalid characters»:** скрытые символы при копировании. Введите ключ заново.
- **Gemini не вернул картинку:** возможно, промпт заблокирован. Попробуйте переформулировать.
- Собственные настройки Студии хранятся под ключом `image_studio` в настройках расширений SillyTavern.
